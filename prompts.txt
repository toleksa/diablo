# prompts.txt - image generation requests for Infernal Crucible
# These prompts are sent to an image generation model one at a time to produce
# high-quality replacement art. Each block below is SELF-CONTAINED: the shared
# style anchor and the palette are already written into every prompt, so you can
# copy a PROMPT paragraph and paste it into the generator as it stands.
#
# How to use a block:
#   PROMPT   -> paste into the generator as the positive prompt, verbatim
#   NEGATIVE -> paste into the "negative prompt" field when the tool has one;
#               otherwise append " - avoid: ..." to the end of the PROMPT
#   FORMAT   -> width x height and aspect the generator must output
#   USE      -> which part of the game this asset replaces once it lands
#
# The wording follows ART_BIBLE.md: the same palette (names AND hex codes), the
# same material and silhouette language, the same "painterly detail +
# believable materials" rule. Keep every image inside that vocabulary so the
# seven pieces read as one art set when shown together.
#
# Shared STYLE ANCHOR (already expanded inside each PROMPT):
#   "Dark Gothic Fantasy, realistic stylization, painterly detail combined with
#   physically believable materials, weathered stone, aged metal, leather, wood
#   and bone, dramatic intentional lighting with deep obsidian shadows, muted
#   environmental colors, saturated color reserved for magic and important
#   objects, high-production PC action RPG quality, readable silhouette"
# Shared palette: obsidian #171719, charcoal #29282B, ash grey #68666A, bone
# #C6BDAA, antique gold #A98A50, blood burgundy #642A32, muted brown #594536;
# accents: arcane blue #478CCB, infernal orange #D85C27, spectral violet #9567BB.

NOTE - keeping the set coherent
================================================================================
All seven prompts share the ART_BIBLE.md anchor on purpose. When the set is
generated, compare them side by side before anything enters the game: same
light temperature, same material language, same degree of wear, same palette.
If one asset drifts, regenerate only that one with its approved references
(ART_BIBLE.md section 4.4: never redesign an established character
unintentionally). Nothing here may be committed to the game until the whole
set passes that side-by-side check.
